# Pilot Logbook — เว็บแอปบันทึกชั่วโมงบิน

กรอกเที่ยวบินจากมือถือหรือคอมพิวเตอร์ ข้อมูลซิงค์ข้ามอุปกรณ์ ใช้ออฟไลน์ได้ และส่งออกเป็น Excel ได้
โฮสต์ฟรีบน GitHub Pages + เก็บข้อมูลบน Firebase (แผน Spark ฟรี)

## หลักการคำนวณชั่วโมงบิน

- ใช้ **Decimal Hours** ตามตัวเลขที่บันทึกใน Logbook และบวกตัวเลขโดยตรง เช่น `1.25 + 2.375 = 3.625` ชั่วโมง
- ไม่แปลงชั่วโมงเป็นนาที และไม่ตีความเลขทศนิยมเป็นรูปแบบชั่วโมง:นาที
- ยอด Aircraft Type × Duty, ยอดยกมา และยอดสะสม S1–S50 ใช้ค่าตัวเลขชุดเดียวกัน
- การส่งออก Excel เขียนชั่วโมงเป็นค่าตัวเลข ไม่ใช่ข้อความ และเก็บความละเอียดทศนิยมตามข้อมูล (ภายในความแม่นยำตัวเลขของ Excel) พร้อมกำหนด Data Validation ของช่อง Hours เป็นตัวเลข 0–24 ไม่จำกัดเฉพาะรายการ 0.1–5.0
- เมื่อตั้งชื่อ/ชนิด/ลำดับแบบอากาศยานใหม่ ระบบปรับหัวคอลัมน์ สูตร และรายการ Dropdown ใน S1–S50 รวมถึงตาราง Summary ให้ตรงกับรายการปัจจุบัน
- แม่แบบ Excel มีตำแหน่งหน้าที่จำกัดตามช่องแบบอากาศยาน: ช่อง 1–5 รองรับ CP/PI, PC, MP, IP, SP; ช่อง 6 รองรับ CP/PI, PC, SOLO; ช่อง 7 รองรับ CP/PI, SOLO; ช่อง 8 รองรับ CP/PI เท่านั้น ระบบจะแจ้งเตือนหากมียอดยกมาหรือเที่ยวบินที่ไม่มีคอลัมน์รองรับ

ทดสอบตรรกะ Decimal Hours ได้ด้วยคำสั่ง `node --experimental-default-type=module --test tests/decimal-hours.test.mjs` (ต้องใช้ Node.js)

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `style.css`, `app.js` | หน้าจอและการทำงานของแอป |
| `logic.js` | คำนวณยอดรวม/แบ่งหน้า/อ่านไฟล์ Excel เดิม (ตรวจเทียบกับไฟล์เดิมแล้ว) |
| `xlsxfill.js` + `template.xlsx` | ส่งออก Excel: กรอกข้อมูลลงไฟล์แม่แบบ = ต้นฉบับที่ล้างข้อมูลการบินออกแล้ว (ไม่มีข้อมูลส่วนตัว) |
| `backend.js` | เชื่อม Firebase (หรือโหมดในเครื่องถ้ายังไม่ตั้งค่า) |
| `firebase-config.js` | **ไฟล์เดียวที่ต้องแก้** ใส่ค่า config ของ Firebase |
| `firestore.rules` | กฎความปลอดภัย: ผู้ใช้เข้าถึงได้เฉพาะข้อมูลของตัวเอง |
| `sw.js`, `manifest.webmanifest`, `icons/` | ติดตั้งเป็นแอปบนมือถือ + ใช้ออฟไลน์ |

## ขั้นตอนติดตั้ง (ประมาณ 15 นาที)

### 1) สร้างโปรเจกต์ Firebase (ฟรี)
1. เข้า <https://console.firebase.google.com> → **Add project** (ตั้งชื่อเช่น `pilot-logbook`, ปิด Google Analytics ได้)
2. หน้าโปรเจกต์ กดไอคอน **`</>` (Web)** → ตั้งชื่อแอป → **Register app** (ไม่ต้องติ๊ก Hosting)
3. จะเห็นก้อน `firebaseConfig` → คัดลอกค่า `apiKey`, `authDomain`, `projectId`, `appId` ไปวางใน **`firebase-config.js`**

### 2) เปิดระบบล็อกอิน Google
**Build → Authentication → Get started → Sign-in method → Google → Enable** (เลือกอีเมลของคุณเป็น support email) → Save

### 3) สร้างฐานข้อมูล Firestore
1. **Build → Firestore Database → Create database**
2. Location เลือก `asia-southeast1` (สิงคโปร์) → เลือก **Production mode**
3. แท็บ **Rules** → ลบของเดิม วางเนื้อหาจาก `firestore.rules` → **Publish**

> เข้มกว่านั้นได้: เปลี่ยนเงื่อนไขเป็น `request.auth.token.email == 'อีเมลของคุณ@gmail.com'` เพื่อให้มีแค่บัญชีคุณเท่านั้น

### 4) อัปขึ้น GitHub Pages
1. สร้าง repo ใหม่บน GitHub (ตั้งเป็น **Public** — Pages ฟรีใช้กับ repo สาธารณะ)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ลากวางผ่านหน้าเว็บได้ หรือใช้ `git push`)
3. **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`

### 5) อนุญาตโดเมนให้ล็อกอินได้
Firebase → **Authentication → Settings → Authorized domains → Add domain** → ใส่ `ชื่อผู้ใช้.github.io`
(ถ้าข้ามขั้นนี้ ปุ่มล็อกอินจะแจ้งว่าโดเมนไม่ได้รับอนุญาต)

### 6) ใช้งานครั้งแรก
1. เปิดลิงก์ในข้อ 4 → **เข้าสู่ระบบด้วย Google**
2. แท็บ **ตั้งค่า → นำเข้าจากไฟล์ Excel** เลือกไฟล์ `3_Pilot_Logbook_...xlsx`
   - นำเข้าเที่ยวบินทั้งหมดจากชีต S1–S50
   - นำเข้า **ยอดยกมา** จากช่อง Total Last Page ของ S1 ให้อัตโนมัติ
3. มือถือ: เปิดลิงก์ในเบราว์เซอร์ → **Add to Home Screen** (iPhone: ปุ่มแชร์ → Add to Home Screen) จะใช้เหมือนแอป

## วิธีใช้
- **บันทึก**: กรอกเที่ยวบิน กดปุ่ม `= ชม.บิน` ข้างช่อง X-Country/Night/IMC เพื่อใส่เท่าชั่วโมงบิน หลังบันทึก ต้นทางเที่ยวถัดไปจะเติมเป็นปลายทางเที่ยวก่อนให้
- **รายการ**: แสดงเป็นหน้าละ 18 รายการเหมือนในสมุด พร้อมยอดสะสม แตะรายการเพื่อแก้ไข/ลบ ค้นหาได้
- **สรุป**: ชั่วโมงตามแบบ × หน้าที่, Single/Multi, Night, IMC ฯลฯ และชั่วโมง 30/90/365 วันล่าสุด
- **ตั้งค่า**: ยอดยกมา, นำเข้า/ส่งออก Excel, สำรอง/กู้คืน JSON

## หน้าตาและการใช้งานบนมือถือ/ไอแพด
- **มือถือ**: เมนูอยู่ล่างจอ ปุ่มบันทึกติดขอบล่างตลอด เลือกแบบอากาศยาน/หน้าที่ด้วยชิป (ไม่ต้องเปิด dropdown) ปรับชั่วโมงบินด้วยปุ่ม − / + ได้
- **ไอแพด**: เมนูย้ายไปแถบด้านข้าง ถ้าจอกว้างพอ (แนวนอน) จะแสดง "เที่ยวบินล่าสุด" ข้างฟอร์ม แตะเพื่อแก้ไขได้ทันที
- **ธีม**: แท็บ ตั้งค่า → ธีมและการแสดงผล เลือกโหมด อัตโนมัติ/สว่าง/มืด และสีหลัก 4 แบบ (เขียวทหาร, น้ำเงินกรมท่า, เขียวมรกต, เทาถ่าน) ระบบจำค่าที่เลือกไว้ในเครื่องนั้น
- **ภารกิจ**: แตะชิปเหมือนช่องหน้าที่ (ชุดเดียวกับรายการเลือกในไฟล์ Excel) แตะซ้ำเพื่อยกเลิก หรือกด “อื่นๆ (พิมพ์เอง)” ภารกิจที่พิมพ์เองจะถูกจำเป็นชิปให้ครั้งต่อไป
- **สภาพการบิน** (X-Country, Night, NVG, IFR, IMC): แตะชิปเพื่อเลือก ค่าจะเท่าชั่วโมงบินและตามเมื่อแก้ชั่วโมงบิน ถ้าบินกลางคืนแค่บางส่วนให้แก้ตัวเลขในช่องได้
- **ลำดับข้อมูล**: เที่ยวบินที่เพิ่มหรือแก้วันที่ภายหลังจะแทรกตามวันที่ให้อัตโนมัติ ส่วนข้อมูลที่นำเข้ามาก่อนหน้า (ซึ่งเรียงตามลำดับที่กรอกในไฟล์เดิม) กดเรียงใหม่ได้ที่ ตั้งค่า → ลำดับข้อมูล → เรียงข้อมูลใหม่ตามวันที่ (ควรสำรอง JSON ก่อน เพราะรายการที่ย้ายอาจข้ามหน้าและไฟล์ Excel ที่ส่งออกจะเปลี่ยนตาม)

## หลายผู้ใช้ / แบบอากาศยานของแต่ละคน / ความเป็นส่วนตัว
- **แต่ละคนใช้บัญชี Google ของตัวเอง** ข้อมูลแยกตามบัญชี (`firestore.rules`) คนอื่นเปิดดูของคุณผ่านแอปไม่ได้ แต่คุณซึ่งเป็นเจ้าของโปรเจกต์ Firebase เปิดดูฐานข้อมูลใน Firebase Console ได้ทางเทคนิค ควรแจ้งผู้ใช้ให้ทราบ (ข้อความนี้อยู่ในหน้าต้อนรับและนโยบายความเป็นส่วนตัวในแอปแล้ว)
- **ผู้ใช้ใหม่** จะเห็นหน้าต้อนรับ 3 ขั้น: แนะนำแอป + ความเป็นส่วนตัว → ตั้งรายการแบบอากาศยาน → ใส่ยอดสะสม/นำเข้า Excel/เริ่มบันทึก (ผู้ใช้เดิมที่มีข้อมูลอยู่แล้วจะไม่เห็น)
- **รายการแบบอากาศยานของแต่ละคน** (ตั้งค่า → แบบอากาศยานของฉัน) สูงสุด 8 แบบ เปลี่ยนชื่อ/ลบ/เรียงลำดับ และเลือกชนิดเครื่องยนต์ได้ เก็บใน Firestore ที่ `users/{uid}/meta/config` (กฎเดิมครอบคลุมอยู่แล้ว ไม่ต้องแก้)
- **ไฟล์ Excel ที่ส่งออก** จะปรับชื่อแบบอากาศยานในสูตร หัวคอลัมน์ รายการ dropdown และชีต Summary ให้ตรงกับรายการของแต่ละคนอัตโนมัติ (ถ้าเป็นชุดเริ่มต้นจะใช้แม่แบบเดิมทุกประการ)
  - แม่แบบมี 8 ช่อง ช่องลำดับ 1–5 มีคอลัมน์ครบทุกหน้าที่ (CP/PI, PC, MP, IP, SP) ลำดับ 6 มี CP/PI และ PC ลำดับ 7–8 มีเฉพาะ CP/PI เที่ยวบินที่หน้าที่ไม่มีคอลัมน์ยังนับในชั่วโมงรวม แอปจะแจ้งตอนส่งออก
- **ลบข้อมูลของตัวเอง**: ตั้งค่า → ข้อมูลของฉัน → ลบข้อมูลทั้งหมด (บัญชีล็อกอินในระบบ Authentication ของ Firebase ยังอยู่ ลบได้โดยผู้ดูแลที่ Firebase Console → Authentication → Users)
- **ข้อความนโยบายความเป็นส่วนตัว** อยู่ใน `index.html` (`<dialog id="dlg-privacy">`) เป็นแบบร่างทั่วไป ตรวจและแก้ให้ตรงกับที่คุณทำจริงก่อนเปิดให้คนอื่นใช้ (เช่น ใส่ช่องทางติดต่อผู้ดูแล)

## อุปกรณ์ที่รองรับ และข้อควรรู้เรื่องโควตา
- **รองรับ**: iPhone/iPad iOS 15.4 ขึ้นไป, Android (Chrome 90+), เบราว์เซอร์เดสก์ท็อปรุ่นปัจจุบัน (Chrome/Edge/Safari/Firefox) รุ่นที่เก่ากว่านี้อาจเปิดหน้าต่างยอดยกมา/แบบอากาศยานไม่ได้
- **ล็อกอินในแอปที่ติดตั้งบนหน้าจอโฮมของ iPhone/iPad**: Google อาจไม่อนุญาตหน้าต่างล็อกอิน (ป๊อปอัป) ในโหมดนั้นบางรุ่น ถ้าล็อกอินไม่สำเร็จ ให้ใช้งานผ่าน Safari ตามปกติ (เก็บลิงก์เป็นบุ๊กมาร์ก) แทนการติดตั้ง
- **โควตาฟรีของ Firebase (Spark)**: อ่าน 50,000 และเขียน 20,000 ครั้งต่อวัน การเปิดแอปบนเครื่องที่ยังไม่มีแคชจะอ่านเที่ยวบินทั้งหมดของผู้ใช้ 1 ครั้ง (เช่น 900 เที่ยว = 900 ครั้ง) ผู้ใช้หลายสิบคนยังเหลือเฟือ ถ้าเปิดกว้างมากให้จำกัดอีเมลที่ใช้ได้ด้วยตัวเลือกใน `firestore.rules`

## ข้อควรรู้
- **ความเป็นส่วนตัว**: repo เก็บเฉพาะโค้ด ข้อมูลการบินอยู่ใน Firebase ของคุณ อย่าอัปโหลดไฟล์ `.xlsx` หรือไฟล์สำรอง `.json` ขึ้น repo สาธารณะ (`.gitignore` กันไว้ให้แล้ว)
- **ออฟไลน์**: กรอกได้ตามปกติ พอมีเน็ตจะซิงค์เอง (ป้ายมุมซ้ายบนบอกสถานะ ซิงค์แล้ว/กำลังซิงค์/ออฟไลน์) ต้องเปิดแอปแบบมีเน็ตอย่างน้อยหนึ่งครั้งก่อน
- **ไฟล์ Excel ที่ส่งออก** ใช้ไฟล์ต้นฉบับเป็นแม่แบบ จึงได้ชีต Summary + S1–S50, สูตร, สี, เส้น, dropdown เหมือนเดิมทุกอย่าง แอปกรอกเฉพาะช่องข้อมูล (วันที่ แบบ หมายเลข ต้นทาง ปลายทาง ภารกิจ หน้าที่ ชั่วโมง สภาพการบิน หมายเหตุ) และยอดยกมาที่ S1
  - รองรับสูงสุด 900 เที่ยวบิน (50 ชีต × 18 แถว) ถ้าเกิน ต้อง Duplicate ชีตในไฟล์ `template.xlsx` เพิ่ม
  - สูตรจะคำนวณตอนเปิดไฟล์ ให้เปิดด้วย Excel / Google Sheets / LibreOffice (ตัวดูไฟล์แบบพรีวิวบนมือถืออาจแสดงช่องสูตรว่าง)
  - ลำดับรายการเป็นลำดับที่กรอก (เหมือนสมุดล็อกบุ๊ก) เที่ยวใหม่ต่อท้ายเสมอ
  - **ต้องอัป `template.xlsx` ขึ้น GitHub ด้วย** ไม่เช่นนั้นปุ่มส่งออกจะใช้ไม่ได้
- **โควตาฟรีของ Firebase Spark** (อ่าน 50,000 / เขียน 20,000 ครั้งต่อวัน) มากเกินพอสำหรับล็อกบุ๊กส่วนตัว
- ถ้าอยากแก้โค้ดแล้วผู้ใช้ไม่เห็นของใหม่ ให้เปลี่ยนเลขใน `CACHE = 'pilot-logbook-v10'` ในไฟล์ `sw.js`

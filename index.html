ลำดับข้อมูล

เที่ยวบินที่เพิ่มหรือแก้วันที่ภายหลังจะแทรกตามวันที่ให้อัตโนมัติ ส่วนข้อมูลที่นำเข้ามาแล้วอาจยังเรียงไม่ตรงวันที่ กดปุ่มด้านล่างเพื่อเรียงใหม่ทั้งหมด

นำเข้า / ส่งออก

ส่งออกเป็นไฟล์รูปแบบเดียวกับต้นฉบับทุกอย่าง (ชีต Summary + S1–S50 พร้อมสูตร) เปิดด้วย Excel หรือ Google Sheets · แม่แบบเปล่าใช้กรอกด้วยมือหรือเป็นต้นทางก่อนนำเข้า

ข้อมูลของฉัน

ข้อมูลของคุณเห็นได้เฉพาะบัญชีนี้ คุณส่งออกหรือลบข้อมูลทั้งหมดได้ด้วยตัวเอง

วิธีใช้งาน

แตะหัวข้อเพื่ออ่าน

เริ่มต้นใช้งาน 4 ขั้น
  1. เข้าสู่ระบบด้วยบัญชี Google
  2. ตั้งรายการแบบอากาศยานของคุณ (ตั้งค่า → แบบอากาศยานของฉัน)
  3. ใส่ชั่วโมงเดิม ถ้ามีสมุดหรือไฟล์ Excel อยู่แล้ว: นำเข้าจากไฟล์ (ตั้งค่า → นำเข้า/ส่งออก) หรือพิมพ์ยอดยกมาเอง (ตั้งค่า → ยอดยกมา)
  4. กรอกเที่ยวบินที่แท็บ “บันทึก” ยอดรวมที่มุมขวาบนจะเพิ่มให้ทันที
บันทึกเที่ยวบิน
  • ชั่วโมงบิน: พิมพ์ หรือกดปุ่ม − / + ครั้งละ 0.1
  • แบบอากาศยาน / หน้าที่: แตะชิปเพื่อเลือก (CP/PI, PC, MP, IP, SP, SOLO)
  • ภารกิจ: แตะชิป (ชุดเดียวกับรายการเลือกในไฟล์ Excel) แตะซ้ำเพื่อยกเลิก ถ้าไม่มีให้กด “อื่นๆ (พิมพ์เอง)” แล้วพิมพ์ แอปจะจำไว้เป็นชิปให้ครั้งต่อไป
  • ต้นทาง ปลายทาง: พิมพ์ได้อิสระ แอปจำคำที่เคยใช้ให้เลือก หลังบันทึก ต้นทางเที่ยวถัดไปจะเติมจากปลายทางเที่ยวก่อน
  • สภาพการบิน (X-Country, Night, NVG, IFR, IMC): แตะชิปเพื่อเลือก ค่าเริ่มต้นเท่าชั่วโมงบิน ถ้าเป็นแค่บางส่วนให้แก้ตัวเลขที่ปรากฏข้างชิป
  • กด บันทึกเที่ยวบิน (ปุ่มติดขอบล่างของจอ)
แก้ไขหรือลบเที่ยวบิน

ที่แท็บ “รายการ” แตะเที่ยวบินที่ต้องการ (บนไอแพดแนวนอนแตะจาก “เที่ยวบินล่าสุด” ได้เลย) แก้ข้อมูลแล้วกดบันทึก หรือกด “ลบ” หากแก้วันที่ รายการจะย้ายไปตามวันที่ใหม่เอง

รายการ ยอดสะสม และการค้นหา

รายการแบ่งเป็นหน้าละ 18 เที่ยวบินเหมือนสมุดล็อกบุ๊ก แต่ละหน้าแสดงยอดหน้านี้และยอดสะสม ช่องค้นหาหาได้จากสถานที่ แบบอากาศยาน ภารกิจ วันที่ หรือหมายเหตุ

หน้าสรุป

แสดงชั่วโมงตามแบบอากาศยาน × หน้าที่ ชั่วโมงเครื่องยนต์เดียว/หลายเครื่องยนต์ กลางคืน NVG IMC และชั่วโมงบิน 30/90/365 วันล่าสุด (นับเฉพาะที่บันทึกในแอป ไม่รวมยอดยกมา)

ตั้งรายการแบบอากาศยานของคุณ
  • ไปที่ ตั้งค่า → แบบอากาศยานของฉัน เพิ่ม เปลี่ยนชื่อ ปิดใช้งาน หรือเรียงลำดับได้ และกำหนด Flight Duty แยกตาม Aircraft
  • เลือกชนิดเครื่องยนต์ของแต่ละแบบ (เครื่องยนต์เดียว / หลายเครื่องยนต์ / เครื่องฝึกบินจำลอง) แอปใช้คำนวณยอดและไฟล์ Excel
  • เปลี่ยนชื่อแบบ: เที่ยวบินเก่าและยอดยกมาจะเปลี่ยนชื่อตามให้อัตโนมัติ
  • ลบแบบที่ยังมีเที่ยวบินอยู่ไม่ได้ ให้แก้ชื่อในแถวเดิมแทน
  • ลำดับมีผลกับไฟล์ Excel: แบบลำดับที่ 1–5 มีคอลัมน์ครบทุกหน้าที่ (CP/PI, PC, MP, IP, SP) ลำดับที่ 6 มี CP/PI และ PC ลำดับที่ 7–8 มีเฉพาะ CP/PI จึงควรเรียงแบบที่บินบ่อยและมีหลายหน้าที่ไว้ข้างบน
ยอดยกมา

คือชั่วโมงสะสมก่อนเริ่มใช้แอป (เท่ากับช่อง Total Last Page ของหน้าแรกในสมุด/ไฟล์ Excel) ตั้งที่ ตั้งค่า → ยอดยกมา กรอกตามแบบ × หน้าที่ แล้วใส่ยอดรวมอื่นๆ ถ้ามี ช่องรวมที่เว้นว่างจะคำนวณให้เอง การนำเข้าไฟล์ Excel จะดึงยอดนี้ให้อัตโนมัติ

นำเข้าและส่งออก Excel
  • นำเข้า: ใช้ไฟล์ที่เป็นแม่แบบสมุดล็อกบุ๊กเดียวกับของระบบ (ชีต S1, S2, …) เที่ยวบินที่ซ้ำกับที่มีอยู่จะข้ามให้ ถ้าไฟล์ใช้แบบอากาศยานที่ยังไม่มีในรายการ แอปจะถามว่าให้เพิ่มหรือใช้ตามไฟล์
  • ส่งออก: ได้ไฟล์รูปแบบเดียวกับต้นฉบับ (สูตร สี เส้นครบ) ชื่อแบบอากาศยานตามรายการของคุณ รองรับ 900 เที่ยวบิน (50 ชีต) เปิดด้วย Excel / Google Sheets ซึ่งจะคำนวณสูตรตอนเปิดไฟล์
  • ต้องต่อเน็ตเมื่อนำเข้า/ส่งออกครั้งแรก เพราะแอปโหลดตัวช่วยอ่าน/เขียนไฟล์
เรียงลำดับตามวันที่

เที่ยวบินที่เพิ่มหรือแก้วันที่ภายหลังจะแทรกตามวันที่ให้อัตโนมัติ ถ้าข้อมูลที่นำเข้ามาเรียงไม่ตรงวันที่ ไปที่ ตั้งค่า → ลำดับข้อมูล → เรียงข้อมูลใหม่ตามวันที่ (รายการที่ย้ายอาจข้ามหน้า ยอดต่อหน้าจึงเปลี่ยน แต่ยอดรวมเท่าเดิม)

สำรองและกู้คืนข้อมูล

ตั้งค่า → นำเข้า/ส่งออก → “สำรองข้อมูล (JSON)” ได้ไฟล์ที่เก็บเที่ยวบิน ยอดยกมา และรายการแบบอากาศยาน เก็บไว้ในที่ปลอดภัย ใช้ “กู้คืนจากไฟล์สำรอง” เมื่อเปลี่ยนเครื่องหรือต้องการย้อนกลับ

ซิงค์ข้ามอุปกรณ์และใช้ออฟไลน์
  • ล็อกอินบัญชีเดียวกันบนทุกเครื่อง ข้อมูลจะตรงกัน
  • ป้ายมุมซ้ายบน: ซิงค์แล้ว = ข้อมูลอยู่บนเซิร์ฟเวอร์ครบ, กำลังซิงค์ = กำลังส่ง, ออฟไลน์ = ยังไม่มีเน็ต, ผิดพลาด = เซิร์ฟเวอร์ปฏิเสธการอ่าน/เขียน (ดูข้อความแจ้งเตือน)
  • กรอกตอนไม่มีเน็ตได้ แอปเก็บไว้ในเครื่องและส่งให้เองเมื่อมีสัญญาณ (ต้องเปิดแอปตอนมีเน็ตอย่างน้อยหนึ่งครั้งก่อน และอย่าลบข้อมูลเบราว์เซอร์ก่อนซิงค์เสร็จ)
ติดตั้งบนหน้าจอหลัก (มือถือ/ไอแพด)
  • iPhone/iPad (Safari): ปุ่มแชร์ → เพิ่มลงในหน้าจอโฮม
  • Android (Chrome): เมนู ⋮ → ติดตั้งแอป หรือ เพิ่มลงในหน้าจอหลัก
ธีมและการแสดงผล

ตั้งค่า → ธีมและการแสดงผล เลือกโหมดสว่าง/มืด/อัตโนมัติ และสีหลัก 4 แบบ ค่านี้จำไว้ในแต่ละเครื่อง

ความเป็นส่วนตัว

ข้อมูลของคุณแยกตามบัญชี เห็นได้เฉพาะบัญชีของคุณผ่านแอปนี้ ส่งออกหรือลบทั้งหมดได้ด้วยตัวเอง

แก้ปัญหาเบื้องต้น
  • ข้อมูลไม่ตรงกันระหว่างเครื่อง: ดูป้ายสถานะซิงค์ รอให้เป็น “ซิงค์แล้ว” หรือปิดแล้วเปิดแอปใหม่
  • ส่งออก/นำเข้า Excel ไม่ได้: ต้องต่อเน็ตเพื่อโหลดตัวช่วยครั้งแรก ลองใหม่เมื่อมีสัญญาณ
  • ยอดใน Excel ว่างหรือไม่ตรงในหน้าพรีวิว: เปิดด้วย Excel หรือ Google Sheets เพื่อให้คำนวณสูตรใหม่
  • เห็นหน้าเก่าหลังมีการอัปเดต: ปิดแอปแล้วเปิดใหม่ หรือรีเฟรชหน้าเว็บ (Ctrl+Shift+R)
  • ล็อกอินไม่ได้: อนุญาตป๊อปอัปของเว็บนี้ แล้วกดเข้าสู่ระบบใหม่ ถ้าใช้แอปที่ติดตั้งบนหน้าจอโฮมของ iPhone/iPad แล้วล็อกอินไม่สำเร็จ ให้เปิดผ่าน Safari ตามปกติแทน

ยอดยกมา

แบบอากาศยานของฉัน

เพิ่มได้มากกว่า 8 แบบ กำหนด Duty แยกตาม Aircraft ได้ ลำดับมีผลเฉพาะการจับคู่ช่องใน Excel Template รุ่นเดิม

ความเป็นส่วนตัวของข้อมูล

ข้อมูลที่เก็บ

  • ชื่อและอีเมลของบัญชี Google ที่ใช้เข้าสู่ระบบ (ใช้ยืนยันตัวตนเท่านั้น)
  • ข้อมูลที่คุณกรอกเอง: วันที่ แบบและหมายเลขอากาศยาน ต้นทาง–ปลายทาง ภารกิจ หน้าที่ ชั่วโมงบิน สภาพการบิน หมายเหตุ ยอดยกมา และรายการแบบอากาศยานของคุณ

เก็บที่ไหน

บนบริการ Firebase (Google Cloud) ของผู้ดูแลระบบแอปนี้ และมีสำเนาในเบราว์เซอร์ของอุปกรณ์คุณเพื่อให้ใช้ออฟไลน์ได้ การตั้งค่าธีมเก็บในเครื่องของคุณเท่านั้น

ใครเข้าถึงได้

  • ข้อมูลแยกตามบัญชี ผู้ใช้คนอื่นเปิดดูข้อมูลของคุณผ่านแอปไม่ได้ (กฎของฐานข้อมูลอนุญาตเฉพาะเจ้าของบัญชี)
  • ผู้ดูแลระบบซึ่งเป็นเจ้าของโปรเจกต์ Firebase มีสิทธิ์ทางเทคนิคเปิดดูฐานข้อมูลได้
  • Google ในฐานะผู้ให้บริการ จัดเก็บและประมวลผลข้อมูลตามเงื่อนไขของ Google และ Firebase

สิ่งที่แอปนี้ไม่ทำ

ไม่มีโฆษณา ไม่ติดตั้งเครื่องมือวิเคราะห์พฤติกรรมผู้ใช้ และไม่ขายหรือส่งข้อมูลของคุณให้บุคคลอื่น

ข้อควรระวัง

อย่าบันทึกข้อมูลที่เป็นความลับตามระเบียบของหน่วยหรือทางราชการ (เช่น รายละเอียดภารกิจ พิกัด หรือข้อมูลบุคคลอื่น) ลงในช่องภารกิจ ต้นทาง–ปลายทาง หรือหมายเหตุ แนะนำให้ใช้คำทั่วไป

สิทธิ์ของคุณ

  • ส่งออกเป็น Excel หรือสำรองเป็น JSON ได้ทุกเมื่อ (ตั้งค่า → นำเข้า/ส่งออก)
  • ลบข้อมูลทั้งหมดของคุณได้เอง (ตั้งค่า → ข้อมูลของฉัน) การลบเที่ยวบิน ยอดยกมา และการตั้งค่าเป็นการถาวร กู้คืนไม่ได้
  • ชื่อบัญชีล็อกอินยังอยู่ในระบบยืนยันตัวตนของ Firebase หากต้องการให้ลบด้วย ให้แจ้งผู้ดูแลระบบ
